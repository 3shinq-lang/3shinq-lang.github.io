Privacy Policy — Sovereign Assistant

Last updated: 2026-10-05

Sovereign Assistant ("the App") is a personal, self-hosted assistant operated by a single individual for their own use. This policy explains how the App handles information, including information obtained from Google APIs.

1. Information the App accesses

When the owner authorizes the App, the App may access the owner's own Google Calendar data through the Google Calendar API, using the following scopes:

  • https://www.googleapis.com/auth/calendar.readonly — view the owner's calendars and events.
  • https://www.googleapis.com/auth/calendar.events — view and edit the owner's events.

The App accesses no calendar data other than that of the owner who granted consent.

2. How the information is used

Calendar data is used solely to display and manage the owner's own events within the App (for example, listing upcoming events or creating an event requested by the owner).

3. Storage and security

OAuth credentials and tokens are stored locally on the owner's own computer (for example in a local token.json file). The App does not operate a remote server that stores this data. Data is transmitted only between the owner's computer and Google's APIs over encrypted connections.

4. Sharing and disclosure

The App does not sell, rent, or share the owner's Google user data with any third party. Data is not used for advertising or profiling.

5. Google API Services User Data Policy — Limited Use

Sovereign Assistant's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

The owner can revoke the App's access at any time from their Google Account (myaccount.google.com/permissions), and can delete the locally stored token file to remove stored credentials. Once access is revoked and the local token is deleted, the App can no longer access any Google data.
